# HAXNEX E-Commerce Platform

A modern e-commerce web application built using React, TypeScript, and Vite.

## Features

* User Authentication
* Product Catalog
* Shopping Cart
* Responsive UI
* Modern Component Architecture
* GitHub-ready Project Structure

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* PNPM

## Getting Started

```bash
pnpm install
pnpm run dev
```

## Project Structure

* src/ - Application source code
* public/ - Static assets
* components.json - UI configuration
* vite.config.ts - Vite configuration
